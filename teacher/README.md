# Панель преподавателя

Из корня проекта после установки общих зависимостей:

```powershell
python -m teacher
```

Панель читает сессии из `PROCTOR_DATA_DIR/proctoring.db` (по умолчанию
`data/proctoring.db`). Исходная база открывается только для чтения. Решения,
комментарии и отметки ложных срабатываний хранятся отдельно в
`teacher/state/reviews.db`.

На странице сессии панель показывает:

- контрольный кадр студента из начала теста (личность сверяет преподаватель,
  распознавание лиц не используется);
- заключение системы — короткий текст по правилам из записанных событий
  (`teacher/conclusion.py`); это подсказка, а не вердикт;
- кнопку «Сохранить отчёт»: отчёт по сессии одним HTML-файлом с кадрами,
  таймлайном и решением преподавателя (`teacher/report.py`). Файл открывается
  в любом браузере и печатается в PDF.

Учебные данные:

```powershell
python -m teacher.seed_demo
python -m teacher --demo
```

Генератор создаёт базу того же формата и кадры-заглушки в
`teacher/demo_data/`. Повторный запуск обновляет только шесть demo-сессий.
Для другой базы можно указать `--db ПУТЬ`, для отдельного файла решений —
`--reviews ПУТЬ`.

Тесты:

```powershell
python -m unittest discover -s teacher -p "test_*.py" -v
```

В старых сессиях может не быть имени студента: основное приложение пока
записывает в `metadata_json` только `application`. В таком случае панель
покажет начало идентификатора сессии. Длительность берётся из `duration`
или `duration_seconds` в событии; если поле отсутствует, она неизвестна.
Пересчёт риска повторяет правила `core.risk` по времени событий и исключает
отмеченные ложные срабатывания.
