# Передача Максу: подключение модуля взгляда

Готовая часть находится в папке `gaze/`. Она анализирует кадр из общей камеры
и возвращает события, совместимые с общим `events.py`.

## Что подключить

1. Поместить `gaze/` рядом с общими `main.py` и `events.py`.
2. Добавить версии из `gaze/requirements.txt` в общие зависимости.
3. В адаптере использовать имя модуля **`gaze`**:
   `PROCTOR_GAZE_MODULE=gaze`.
4. Передавать тот же исходный BGR-кадр, который получает детектор телефона.
   Второй захват камеры для этого модуля не создавать.

Пример вызова в общем рабочем потоке:

```python
from events import ProctorEvent
import gaze


def process_gaze_frame(frame) -> tuple[list[ProctorEvent], float | None]:
    events = gaze.analyze(frame)
    ratio = gaze.get_face_width_ratio()
    return events, ratio
```

`events` содержит точные экземпляры общего `events.ProctorEvent`.
Внутри пакета общего контракта событий нет: не копировать `events.py`
в `gaze/` и не создавать отдельный класс с тем же именем.
Корневой `gaze_analyzer.py` обеспечивает совместимость старого имени;
для нового подключения использовать `gaze`.

## События и журнал

Модуль использует только эти пять существующих значений `EventType`:

| `event.type.value` | Порог по умолчанию |
| --- | --- |
| `gaze_side` | 3 с |
| `gaze_down` | 5 с |
| `no_face` | 2 с |
| `multiple_faces` | 1 с |
| `too_close_to_camera` | Ширина лица > 0.45 непрерывно 3 с |

Новые значения перечисления добавлять не нужно. Для близости используется
уже существующий `EventType.TOO_CLOSE_TO_CAMERA`.
`event.source` — `gaze`; время регистрации находится в `event.occurred_at`.
Метаданные доступны через `event.details`:

- `duration` — наблюдаемая длительность эпизода к моменту события;
- `timestamp`, `started_at` — секунды монотонной шкалы анализа;
- `face_count` — число обнаруженных лиц;
- `face_width_ratio` — доля ширины кадра, когда доступна;
- `head_pose`, `iris_x`, `iris_y` — дополнительные доступные измерения.

Например: `event.details["duration"]`, а не `event.duration`.
`timestamp` не следует отображать как время суток: для таймлайна используйте
`occurred_at`. Событие выдаётся один раз за непрерывный эпизод, затем
возобновляется после прекращения условия. Не умножать его баллы каждый кадр.

## Индикатор близости в интерфейсе

После `gaze.analyze(frame)` опрашивать `gaze.get_face_width_ratio()`.
Повторный вызов анализа только для этого индикатора не нужен.
Передавать полученное число в GUI сигналом из рабочего потока:

```python
ratio = gaze.get_face_width_ratio()
label = "Размер лица недоступен" if ratio is None else f"Ширина лица: {ratio:.0%} кадра"
```

`0.45` — **45% ширины изображения**, а не сантиметры до камеры.
Это разница крайних координат X по 36 точкам овала лица, с ограничением
видимой области `[0, 1]`. При отсутствии/нескольких лицах, нулевой ширине
или неконечных координатах X возвращается `None`.
Для одного лица оценка может быть доступна даже без надёжной оценки головы
или радужек. Если лицо частично выходит из кадра, учитывается видимая ширина.

Правило события: **строго `ratio > 0.45` не менее 3 с**. Значение ровно
`0.45` не срабатывает. Условие ниже/равно порогу, неизвестная ширина или
слишком большой пропуск кадров сбрасывают эпизод. Настройка клавиатуры
не исключает событие близости. Пороги задаются через
`AnalyzerConfig.face_too_close_ratio` и `face_too_close_seconds`.

## Калибровка и завершение

Все вызовы анализатора и изменение его профилей выполнять в одном рабочем
потоке. GUI передаёт запрос; рабочий поток собирает около двух секунд
валидные `get_last_result().metrics` при `face_count == 1` и видимых глазах:

```python
gaze.reset_default_timers()
# Собрать минимум 10 валидных FaceMetrics; во время сбора не учитывать
# события взгляда как нарушения.
gaze.calibrate_default_analyzer(samples, target="screen")
# Затем отдельный сбор для клавиатуры:
gaze.calibrate_default_analyzer(keyboard_samples, target="keyboard")
```

Профиль экрана нужен перед профилем клавиатуры. Успешная повторная калибровка
экрана сбрасывает профиль клавиатуры. Флаги можно получить через
`gaze.get_calibration_status()` (`screen`, `keyboard`).
При завершении потока вызвать `gaze.reset_default_analyzer()` для освобождения
Face Mesh. Модуль хранит одну сессию по умолчанию; для нескольких независимых
камер использовать отдельные `GazeAnalyzer` и нормализовать их словари через
общий `events.normalize_events`.

## Зависимости и проверка перед показом

Рекомендуемый runtime — Python 3.11, 64-разрядный. Общие версии:

```text
mediapipe==0.10.21
numpy==1.26.4
opencv-contrib-python==4.11.0.86
jax==0.4.38
jaxlib==0.4.38
```

MediaPipe использует старый Face Mesh API с радужками.
`face_landmarker.task` скачивать не нужно. PySide6 и YOLO относятся к общему
приложению и телефонному модулю, в эти зависимости не включены.

Самостоятельный запуск: `python -m gaze.demo` (**C** — экран, **K** — клавиатура).
Проверки: `python -m unittest discover -s gaze/tests -v`.
Индивидуальная калибровка на реальном пользователе ещё не подтверждена.
Перед показом проверить обычный набор текста, взгляд в стороны/вниз,
отсутствие лица, второго человека и приближение/удаление от камеры.
Ширина лица — приближённый признак, пороги требуют настройки в реальных условиях.
